# EcoGestión ♻️
## Sistema de Gestión de Materiales Reciclables

### Descripción del proyecto
EcoGestión es una aplicación desarrollada para organizar y administrar la información relacionada con la recepción de materiales reciclables. Su objetivo es facilitar el registro, la consulta y el seguimiento de los materiales, evitando registros desordenados y pérdidas de información.

### Objetivo
Desarrollar un sistema sencillo de gestión que permita registrar materiales reciclables, mantener organizada la información y consultar estadísticas para facilitar el control de los datos.

### Funcionalidades
- Registro de materiales reciclables.
- Selección de fecha, material, cantidad y unidad de medida.
- Registro de observaciones.
- Consulta, búsqueda y filtrado de registros.
- Modificación y eliminación de registros.
- Estadísticas y resúmenes.
- Gráficos circulares y comparativos.
- Exportación de información a CSV.
- Copias de seguridad de la base de datos.

### Tecnologías utilizadas
- Python
- Flask
- SQLite
- HTML
- CSS

### Instalación y ejecución
1. Descargar o clonar el repositorio.
2. Instalar las dependencias:

   `pip install -r requirements.txt`

3. Ejecutar la aplicación:

   `python app.py`

4. Abrir en el navegador:

   `http://127.0.0.1:5000`

La base de datos SQLite se inicializa automáticamente al ejecutar la aplicación si aún no existe.
